# VIRAGE — mini jeu de course

Un jeu de voiture arcade jouable directement dans le navigateur, sans installation ni dépendance.

## Jouer

Ouvre `index.html` dans un navigateur. Accélère avec **↑ / W**, freine avec **↓ / S** et tourne avec **← → / A D**. Appuie sur **R** pour recommencer. Sur téléphone, utilise les boutons tactiles.

La voiture reste orientée vers le haut de l’écran (le nord) et la caméra tourne doucement pour la suivre. Trois circuits sont disponibles : Prairie, Désert et Looping. Termine trois tours ; les meilleurs temps sont enregistrés dans le navigateur.
